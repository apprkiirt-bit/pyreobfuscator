# pyreobfuscator

Self-contained Python obfuscator. One build produces one `.py` artifact that
runs on stock CPython without installing anything.

Подробная инструкция на русском: [USAGE.md](USAGE.md).

## Quick start

```bash
py -m pyreobfuscator build path/to/project -o dist/app.py
py dist/app.py
```

Directory layout:

```text
project/
  main.py          # entry, or use --entry
  pkg/
    __init__.py
    util.py
```

All local modules under the root are bundled. The entry module is executed as
`__main__`. The artifact keeps `__file__`, `sys.argv`, exit codes, relative
imports, packages and `__name__ == "__main__"` behavior.

## What a build does

- **No source blob.** The artifact contains no `.py` source and no fallback
  compiler. Version mismatch is a hard failure.
- **Register VM.** Eligible functions are lowered to a custom register
  instruction set with per-build opcode numbers. Program constants and code
  live inside encrypted VM blobs, not in `co_consts`. The interpreter is the
  only executor for compiled functions.
- **ChaCha20-Poly1305.** Every module, string table and VM blob has its own
  key derived from the build master key and a per-build salt. AAD binds the
  blob to `module|salt|kind`.
- **Lazy loading.** Modules are decrypted and deserialized on first import.
  No `.pyc` is written.
- **Version lock.** Code objects and VM metadata are tied to the interpreter
  that built them. Build on the target CPython version.
- **CFF.** Control flow flattening with encoded states, randomized block order
  and loop handling for functions that stay native.
- **String pool.** Module-level strings move into an encrypted per-module
  table; constants inside VM functions are in the VM blob. `--numbers` splits
  integer constants.
- **Remapper.** Private module names and function locals are renamed. Runtime
  and crypto helpers are renamed to opaque `IlI...` identifiers; comments and
  docstrings are stripped from the artifact.
- **Anti-tamper.** Whole-file SHA-256 before decryption, AEAD tags, builtin
  and `sys` function identity checks, `sys.settrace`/`setprofile`/
  `sys.monitoring` checks, `meta_path` snapshot, debugger/decompiler module
  blacklist, `IsDebuggerPresent`/`CheckRemoteDebuggerPresent`/`TracerPid`,
  audit hook on trace/profile installation, and a watchdog thread that
  rechecks hash and hooks.
- **No fixed markers.** Only `# generated by pyreobfuscator` remains at the
  top. No `BEGIN`/`END`/`HASH` comments.

## Options

```text
--entry PATH              entry file (default: main.py, __main__.py, or the only .py)
--cff auto|all|off        control flow flattening (default: auto)
--vm auto|all|off         register VM tier (default: auto: all eligible functions)
--numbers                 split integer constants
--no-rename               disable private-name remapping
--no-rename-locals        keep function-local names
--no-checks               disable runtime hook checks and watchdog
--no-selfhash             disable whole-file hash
--no-antidebug            disable native debugger checks
--no-audit                disable the audit hook
--no-strict-env           do not fail on PYTHONINSPECT/PYTHONBREAKPOINT/PYTHONSTARTUP
--watchdog SECONDS        background integrity checks (default: 5)
--seed N                  deterministic build
```

## Threat model

Holds against static inspection, byte patching, naive `exec` monkeypatching,
trace/profile hooks, debugger modules and simple offline unpackers. Compiled
functions are not real CPython code objects, so `dis` does not recover their
logic.

Does not hold against a determined attacker dumping live process memory or
patching the Python runtime. The decryption key is embedded by design: there
is no HWID, license server or external key. A dedicated reverse engineer can
recover it. Obfuscation raises cost; it is not cryptographic secrecy.

Module top-level code and constructs the VM does not support stay native.
Keep sensitive logic in ordinary functions to get VM coverage.

## Tests

```bash
py -m unittest discover -s tests -v
```

Coverage: ChaCha20-Poly1305 RFC vector, codec round-trips, CFF semantics,
register VM semantics (loops, classes, calls, try/except, f-strings), artifact
round-trip, no-source build, tamper rejection, version mismatch, short share
rejection and trace-hook rejection.

## Not in this build

- Cython native tier.
- Full module-body VM for arbitrary Python syntax (classes, generators,
  async, comprehensions and `with` stay native).
