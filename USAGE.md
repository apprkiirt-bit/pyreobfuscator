# pyreobfuscator — инструкция

Обфускатор Python-проектов. На выходе один `.py`-файл. Исходников внутри нет.
Артефакт запускается на той версии CPython, на которой собран.

## 1. Требования

- Python 3.9+ на машине сборки.
- На Windows используй `py`, а не `python` из Microsoft Store.
- Внешние пакеты не нужны, только стандартная библиотека.

```powershell
py -c "import sys; print(sys.version)"
```

## 2. Быстрый старт

Из корня репозитория:

```powershell
py -m pyreobfuscator build C:\path\to\project -o C:\path\to\dist\app.py
py C:\path\to\dist\app.py
```

`project` — папка с `main.py` или `__main__.py`. Все локальные `.py` внутри
папки попадут в бандл.

```text
project/
  main.py
  pkg/
    __init__.py
    util.py
```

Другой entry:

```powershell
py -m pyreobfuscator build C:\path\to\project --entry src\start.py -o dist\app.py
```

Один файл:

```powershell
py -m pyreobfuscator build C:\path\to\script.py -o dist\script.py
```

Соседние модули при сборке одного файла не бандлятся. Если есть импорты —
передавай папку.

## 3. Режимы

По умолчанию:

```powershell
py -m pyreobfuscator build project -o dist/app.py
```

- CFF включён, но не разворачивает циклы.
- Регистровая VM забирает все функции, которые поддерживает.
- Строки и константы шифруются, имена переименовываются.
- Whole-file hash, audit hook, antidebug и watchdog на 5 секунд включены.

Максимально агрессивно:

```powershell
py -m pyreobfuscator build project -o dist/app.py --cff all --vm all --watchdog 2
```

Если библиотека ломается на переименовании:

```powershell
py -m pyreobfuscator build project -o dist/app.py --no-rename --no-rename-locals
```

Если библиотека использует `locals()`, `eval`, интроспекцию или нестандартные
фреймы:

```powershell
py -m pyreobfuscator build project -o dist/app.py --cff off --vm off
```

Для отладки:

```powershell
py -m pyreobfuscator build project -o dist/app.py --no-checks --no-audit --watchdog 0
```

## 4. Флаги

| Флаг | Что делает |
|------|------------|
| `-o, --out PATH` | путь к артефакту |
| `--entry PATH` | entry-файл внутри проекта |
| `--cff auto\|all\|off` | control-flow flattening (по умолчанию `auto`) |
| `--vm auto\|all\|off` | регистровая VM (по умолчанию `auto`) |
| `--threshold N` | порог размера функции для CFF |
| `--numbers` | разбивать целочисленные константы |
| `--no-rename` | не переименовывать приватные модульные имена |
| `--no-rename-locals` | не переименовывать локальные переменные |
| `--no-checks` | отключить проверки хуков и watchdog |
| `--no-selfhash` | отключить whole-file hash |
| `--no-antidebug` | отключить `IsDebuggerPresent`/`CheckRemoteDebuggerPresent`/`TracerPid` |
| `--no-audit` | не ставить audit hook на trace/profile |
| `--no-strict-env` | не падать на `PYTHONINSPECT`, `PYTHONBREAKPOINT`, `PYTHONSTARTUP` |
| `--watchdog SECONDS` | период фоновых проверок (по умолчанию 5) |
| `--seed N` | воспроизводимая сборка |

## 5. Что происходит внутри

1. Парсинг проекта, удаление docstrings и приватных имён.
2. Регистровая VM: функции переводятся в инструкции с рандомными opcode.
3. CFF для функций, которые остались нативными.
4. Пул строк и шифрование констант.
5. Сериализация без `marshal`, ChaCha20-Poly1305 на модуль.
6. Один лаунчер: whole-file hash, проверки, audit hook, watchdog, ленивая
   расшифровка.

В артефакте нет `.py`-исходников и маркеров `BEGIN`/`END`/`HASH`. Есть только
`# generated by pyreobfuscator`. Payload не передаётся в `exec`/`eval`.

## 6. Проверка

```powershell
py dist\app.py
py dist\app.py --help
```

Сравни поведение с оригиналом на своих сценариях. Для меню/CLI проверь все
ветки, включая ошибки и `sys.exit`.

## 7. Ограничения

- Ключ расшифровки лежит внутри артефакта: без HWID/сервера иначе нельзя.
  Это защита от статического чтения, а не криптографическая тайна.
- Дамп живой памяти процесса не блокируется.
- VM поддерживает функции с `if`, циклами, `try/except/finally`, f-strings,
  вызовами, атрибутами, контейнерами, срезами и `global`. Классы, генераторы,
  async, comprehensions, `with`, `match` и вложенные функции остаются
  нативными.
- Top-level модуля остаётся нативным. Держи чувствительную логику в функциях.
- Артефакт привязан к версии CPython сборки. Для другой версии собирай заново.
